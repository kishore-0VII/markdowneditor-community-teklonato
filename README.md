
# Teklonato Markdown Editor

A free, browser-based Markdown editor for writing, previewing,
and exporting Markdown documents.

**[Launch Markdown Editor](https://markdowneditor.teklonato.com/)**

## Features

- Write visually with the Write editor
- Edit raw Markdown in Source mode
- Use Split mode for side-by-side editing and preview
- Open existing `.md` and `.markdown` files
- Support for headings, tables, checklists, and code blocks
- Export documents as Markdown, PDF, or Word
- Copy Markdown tables into spreadsheets
- Work with documents locally in your browser

## Privacy First

Teklonato Markdown Editor is designed to process your
documents in your browser without uploading their content
to a server.
